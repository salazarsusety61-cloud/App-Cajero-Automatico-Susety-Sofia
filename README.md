#  Banco en Línea - Aplicación de Escritorio

## Descripción
Aplicación desarrollada en Python con Tkinter que simula un sistema bancario completo. Permite crear cuentas, iniciar sesión, consultar saldo, depositar, retirar, transferir dinero y ver el historial de transacciones.

## Tecnologías Utilizadas
- **Python 3** — Lógica del programa
- **Tkinter** — Interfaz gráfica de usuario
- **JSON** — Almacenamiento de datos
- **GitHub** — Control de versiones

## Funcionalidades
-  Crear cuenta nueva con número y PIN
-  Inicio de sesión seguro con límite de intentos
-  Consultar saldo disponible
-  Realizar depósitos
-  Realizar retiros
-  Transferencias entre cuentas
-  Historial completo de transacciones con fecha y hora
-  Cambiar PIN de acceso
-  Cerrar sesión
